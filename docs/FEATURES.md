# Historical Filmocity capability inventory (v0.39)

This dated feature list is an implementation inventory, not an assertion that every feature below has native acceptance or full Premiere parity. Filmocity is a local editor that a human and agent can edit together. See [release readiness](RELEASE_READINESS.md) for the exact scoped RC6 Windows results and remaining limits; historical counts and labels below retain their original development scope.

## Editing (Premiere parity — `docs/AUDIT.md` is the menu-by-menu account)
- **Workspaces** Editing · Color · Audio · Graphics · Captions, tab docking, floating panels, layouts that persist; Source/Program/Reference monitors, Trim Edit monitor, Comparison View, Multi-Camera View; timeline with Premiere track headers, render bar, virtualized rendering for large cuts.
- **Tools** Selection, Track Select F/B, Ripple, Rolling, Rate Stretch, Razor, Slip, Slide, Pen, Hand, Zoom, Type, Rectangle, Ellipse, Polygon; snapping, guides, rulers, safe margins, **platform UI overlays**, transparency grid.
- **Edits** insert/overwrite/lift/extract, three-/four-point edits, ripple/roll/slip/slide with readouts and monitor preview, dynamic JKL trimming, trim types, Ctrl-drag insert, Alt-drag duplicate, Add Edit(s), Paste Insert/Attributes, Remove Attributes, nesting, groups, linked/unlinked audio, Breakout to Mono, Extract Audio, Merge Clips, Synchronize, Match Frame / Reverse Match Frame, markers (clip and sequence, chapters export/embed), In/Out, sequence templates, Auto Reframe, **Blur Fill** framing, Time Tuner, Render & Replace, Scene Edit Detection, text-based editing (transcript), **Remove Silences**, Interpret Footage, input colour transforms.
- **Transitions** dissolve, dips, wipes, pushes, slides, iris, diagonals, barn doors, clock, checker, cross-zoom, **glitch**; optional auto sound effects; alignment start/center/end; draggable handles and typed durations; default transitions; audio constant power/gain.
- **Effects** 44 video + 30 audio effects (Effects panel, Effect Controls with hot-text scrubbing), keyframes with easing on transform/opacity/audio/effects and per-layer graphics, masks, blend modes, Track Matte Key, Warp Stabilizer, speed ramps/time remap/holds/reverse/optical flow, effect presets (fourteen bundled, categorised and described: voice, music, looks, stylize, utility), adjustment layers, LUTs (bundled + user), Lumetri-style colour (basic with **Auto** and **Colour Match**, curves, wheels, HSL Secondary, vibrance), scopes (parade, histogram, vectorscope). GPU (WebGL2) preview mirrors LUTs, curves, keys, HSL Secondary exactly.
- **Graphics** Type tool with inline editing on the monitor, layered graphics (text/box/shape/polygon/**image**, gradient fills, drop shadows), **per-layer in/out animations** (fade, rise, drop, slides, pop, zoom, wipes, typewriter, rotate) with easing/delay, per-layer opacity/scale/rotation/glow/blur, **per-layer keyframes**, cascade/mirror, **kinetic word splits**, align & distribute, twenty-four animated templates (twelve **premium**, brand-kit aware), saved graphics templates, **your own fonts**, **brand kit**, vertical text, captions track (auto-captions via faster-whisper, SRT/VTT import/export, styles, **word highlight/pop animation**, inline edit, upgrade to graphic); clip **motion presets** (push/pull/pan/whip/drop/handheld/pulse).
- **Audio** clip and track gain/pan/keyframes, channel mapping, Audio Gain dialog (peak/loudness normalize), buses with EQ/comp/limiter, master fader + limiter, auto-match loudness, ducking, Remix to Duration, **beat markers** from detected tempo, audio meters (master and per track), Web Audio preview graph so what you hear is what exports.
- **Multicam** create from bins, audio sync, cut-and-switch 1–9, flatten.
- **Media** import of the full FFmpeg format range with automatic video and audio proxies, **image sequences**, browse/relink (via Media Browser), background ingest (thumbs, filmstrips, waveforms, proxies), metadata panel with ffprobe details and log fields, nested bins, labels, subclips, synthetic media (black, matte, bars & tone, transparent, counting leader, **animated gradients, light leaks, film grain**) and **generated sound effects**, tagged PQ/HLG→SDR Hable conversion with measured/overridden peak, separate BT.2020 SDR gamut conversion, undoable source-color settings and camera log LUTs (S-Log3, V-Log, C-Log3, LogC3; override automatic conversion). Real camera/display/output qualification remains open, rotation-aware dimensions.
- **Export** explicit SDR Rec.709 matrix/range and matching video tags in full-color mode (native display/camera qualification remains open), Quick Export, twenty presets (H.264/HEVC/ProRes/**WebM**/**AV1**/**MOV**/GIF/PNG/WAV/MP3/AAC), social variants, In–Out range, loudness normalisation, chapters, QA readback (loudness, peak, size, duration, **platform delivery rules**), render queue with progress and cancel, **smart export** (segment cache — change a word and re-encode only that segment), Render Entire Sequence with exact playback, FCP7 XML / OTIO / EDL / SRT / VTT / markers interchange.

- **Ad testing** hook variants (one sequence per headline), section markers, cut summary, deliverables manifest.
- **Review** client review page with time-stamped comments → note markers; review copies with timecode and watermark.
- **Recipes** Talking Head Clip (silences, punch-ins, voice, captions, b-roll), auto-duck, New Reel from Footage (hook, beat-cut shots, blur fill, music remix, CTA, captions, sfx), Dress as Explainer (lower third, chapter cards, end card), Export Cover / Thumbnail — for humans from the menus, for agents via the SDK.

## Collaboration with agents
- Agents use the same project model over HTTP/WebSocket (`docs/AGENT_API.md`, Swagger at `/api/docs`, Python SDK `agent/filmocity_client.py`, worked example `agent/example_agent.py`).
- **Direct edits** appear live and glow green; **proposals** arrive as ghosts on the timeline with reasons, can be previewed in the monitor without applying, and are accepted/rejected with reason codes; **agent mode** switches between direct and proposals-only; **presence** shows where the agent is working; **notes** on clips carry rationale; **review notes** at times can be resolved; project-wide **undo** covers agent ops; **compare to snapshot** shows what changed.
- Server validates every op (422 with reasons), enforces one-clip-per-instant per track, watchdogs stalled renders, keeps rolling backups and versioned schema.

## Learning loop
- Everything is recorded: ops with before-states, proposal decisions with reason codes, agent-vs-human edit pairs, review attention, brief. Export as JSONL (`/api/training/export`).
- **Advisor** (`backend/advisor.py`): trains on decisions and edit pairs, mines rules, scores proposals before they are made (P(accept) badges), records its predictions for calibration; evaluation harness and dataset statistics tools in `agent/`.

## Platform
- Launchers for Windows/macOS/Linux (installer fetches FFmpeg), silent Windows launcher, bundled fonts, System Check, Sample Project, diagnostics, settings that merge safely, `docs/WINDOWS.md`.
- Tests: routes, render, API (incl. smart-export re-export), UI (real mouse events), agent, fuzz, footage (11 awkward formats), **catalog** (every transition/effect/animation/generator rendered and checked). Honest inventory of what is still thin: `docs/GAPS.md`.
