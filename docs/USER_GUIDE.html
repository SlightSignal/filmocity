Filmocity User Guide

Filmocity is a local video editor with a shared human/agent project, familiar editing panels and keyboard controls. This guide walks the interface panel by panel. For the agent's side see docs/AGENT_API.md; for what still differs from Premiere see the feature matrix.

1. Starting

Open the Filmocity shortcut for an already installed native Windows build. For tools-only source, use standard GIL-enabled CPython 3.13.16 x64 and supply reviewed FFmpeg/ffprobe in bin/ or on PATH. Run Install Filmocity.bat in a fresh environment to install the locked dependencies, then Filmocity.bat to open the browser editor. Use the URL reported by that launch; the native package uses its own window. Choose an explicit library with --data; Windows defaults to %USERPROFILE%\filmocity_data. User projects/media are local data and are excluded from the public source. See Windows setup and current qualification limits.

2. The workspace

Menu bar (File · Edit · Clip · Sequence · Markers · Graphics · View · Window · Help) → header bar (Import / Edit / Export modes, project name, workspaces Editing · Color · Audio · Graphics · Captions, undo/redo, Agent proposal / Human final snapshots, Quick Export) → top row: Source dock (Source Monitor, Effect Controls, Audio Clip Mixer) and Program Monitor; optional right dock (Color, Audio Track Mixer, Graphics, Captions & Markers, Proposals, Scopes) → bottom row: Project dock (Project, Media Browser, Effects, History, Info), the tools column, and the Timeline. Drag a panel's tab to another dock to move it; drag the splitters to resize; workspaces remember themselves.

3. Importing

Project → Import uploads files; Media Browser walks folders on this machine (double-click or Import all); File → Import by path takes a list of paths (what the agent uses). Stills default to the Preferences duration. Proxies build in the background; the Program Monitor's resolution menu switches between proxy and full.

4. Editing

Load a clip in the Source Monitor (click it in the bin), mark In/Out (I/O), then , Insert or . Overwrite onto the targeted track (the V1/A1 patch boxes). Tools: V Selection, A Track Select Forward (Shift+A backward), B Ripple, N Rolling, R Rate Stretch, C Razor, Y Slip, U Slide, P Pen (audio keyframes), Rectangle/Ellipse, H Hand, Z Zoom, T Type. Common edits: Ctrl+K add edit, Q/W ripple-trim to playhead, E extend edit, ;/' lift/extract the sequence In–Out, Del/Shift+Del delete/ripple delete, click a gap + Del to close it, click a cut then Ctrl+←/→ to trim it a frame (Shift five, Alt ripple). Right-click a clip for the context menu (enable, speed, hold, nest, link, replace, labels).

Cancel a drag: press Escape during a timeline or Program Monitor drag to restore the original values. Losing window focus or cancelling the input also cancels the preview. Finish or cancel before switching projects or sequences; background refresh waits until the edit finishes. Playback pauses when dragging starts. A single-clip Ctrl-drag inserts and shifts downstream markers with clips; dragging a selected group keeps ordinary group movement. Alt-drag duplicates; a click without movement discards the temporary copy. Effect Controls and Color sliders, numeric label scrubs, keyframe lanes, color wheels and curve editors also support cancellation. Drag a property label to scrub its value; hold Shift for ten times the step. Native slider keyboard controls remain available, and focus returns after a committed value change. Finish or cancel the edit before changing projects.

5. Multicam

Ctrl/Shift-click two or more clips in the Project panel → File → Create Multi-Camera Source Sequence. Drag the new sequence to a video track. Toggle Multi-Camera View (▦ or Shift+0): the grid shows every angle; click one or press 1–9 to cut to it at the playhead.

6. Effects, motion and color

The Effects tab lists transitions and every video/audio effect; double-click or drag one onto a clip. Effect Controls shows Motion (position, scale, rotation, anchor, opacity, blend mode), Time Remapping, Transitions, Volume, the effect stack (enable, reorder, reset, remove), Mask, Video Effects (crop, blur, sharpen, vignette, chroma key), Audio Effects, and Annotate. Every property with the ◷ toggle can be keyframed at the playhead; a lane and a value graph appear (drag points, Alt-drag for bezier handles, click diamonds to cycle easing). Warp Stabilizer: add it from Effects, press Analyze, export. Color (workspace or Window menu): basic correction, temperature/tint/saturation/vibrance, color wheels, curves (master and per channel), bundled LUT looks, Scopes.

Precise values with the keyboard: choose Values… beside a keyframe lane to edit time in seconds from the clip start, value, easing and Bézier handles. Choose a point in the list, or use Add point and Remove point. Bézier time fractions run from 0 to 1; value offsets are relative to the point. Speed keyframes use linear or hold easing. Under Color, each wheel has Values… for red/green/blue adjustments (−1 to 1); the master curve has Edit points… for input/output levels (0 to 1).

Choose Apply to save all dialog changes as one undoable edit. Cancel or Escape before Apply discards the draft. Once Apply starts, closing the window does not cancel that save. Invalid values are explained in the dialog; if the project or selected values changed, close and reopen it. If saving is uncertain, use Recovery before making further edits.

Track Matte Key: add the effect to the clip you want to reveal and enter the source video track ID, such as V2. Choose alpha for transparency or luma for brightness; Invert reverses the result. Turn off that source track’s output to use it only as a matte. Its clips still supply the matte, including their timing and opacity; gaps reveal nothing unless inverted. Missing tracks or circular references must be corrected before export. Use Render In to Out or an export to inspect the result: the live Program Monitor does not display track mattes.

Color preview limitation: color-wheel tonal weights now follow the export filter, but the Program Monitor still approximates other color operations and conversions. Check a short export before relying on a final grade; complete preview/export matching remains in progress.

7. Audio

Drag the yellow gain line on any audio clip; P adds keyframes. Constant-power crossfades with Ctrl+Shift+D. Auto-duck (Audio Track Mixer) writes keyframes under dialogue. Auto-match loudness sets a clip to a target. The Track Mixer has per-track Compressor / DeNoise / Limiter and a master fader + limiter; the export can normalize to −14 LUFS.

8. Graphics and captions

Ctrl+T or the Type tool creates text with system fonts, box, shadow and outline. Graphics templates (12 bundled; save your own) are layered box/shape/text clips. Captions: import SRT, edit on the C1 caption track, style presets, burn-in on export. Optional faster-whisper auto-captioning requires the source-only extra installation, outside the reviewed base dependency locks and RC qualification. Text-based editing: Transcribe, click words to seek, select a range, Delete words.

9. Export

Quick Export / Ctrl+M: format (H.264, HEVC, ProRes, GIF, PNG sequence, WAV/MP3/AAC), encoder, quality, derived outputs (9:16 / 4:5 / 1:1 / 16:9, crop or pad), In–Out range, loudness normalization, presets. Every finished render shows a QA line: resolution, duration, size, integrated loudness, true peak and flags. XML for Premiere/Resolve and OTIO are one click away.

Color processing: Full color is the default and keeps fine color detail while compositing. Choose Legacy — match older exports to use the previous rendering path; colors can differ between the two. This choice is stored in export presets and does not change your project. Older presets without a color setting use Full color. PNG output and Full color nested sequences retain more detail; lossless nested temporary files may require more disk space. Delivery formats such as H.264 still apply their own compression.

Rendered playback: use Sequence → Render Entire Sequence or Render In to Out. Filmocity waits for saves, renders the captured edit, and checks its sources before enabling playback. The Program Monitor status shows progress and a Cancel preview render button. Edits and sequence/project switches make old previews unavailable. View → Play Rendered Preview toggles a completed preview after checking it again. Outside its range and during reverse playback, the monitor uses live preview. Background rendering offers a completed preview without turning it on. After restarting Filmocity, render again; older output files remain in the render folder. Full-sequence previews now use the full renderer and may take longer than cached drafts.

10. Working with the agent

Agent edits arrive live and glow green. Pending proposals appear as dashed ghosts on the timeline; the Proposals tab lets you accept or reject each with reason chips and a note. Preview reviews one item; Preview all reviews the pending set. The review window shows export-rendered frames from a prepared edit: choose a sequence, scrub or step by frame, and inspect normalization notes and project changes. It has no audio playback. Accept reviewed edits applies that prepared edit as one undo step, with your selected notes and reasons. If the project changes or the review expires, close it and preview again. Closing review leaves the project unchanged. Accept All and Reject All keep each item’s note and commit the selected items as one undoable decision. Decisions wait for pending saves and stop if the saved project changed. Use Undo to restore the edits and return the items to pending. Failed decisions are reported without automatically retrying. Agent proposal / Human final snapshots produce structured diffs; playback ranges you review are logged; the Brief (Info panel) travels with every training record. Info → Export training dataset writes one JSONL file.

11. Find commands and edit shortcuts

Choose Commands in the header, Help → Find a command, or press Ctrl+Shift+P. Search editing tools, panels and workspaces by name, task or shortcut. Use the arrow keys to choose, Enter to run, and Escape to close. Commands explain common selection requirements.

Edit → Keyboard Shortcuts lets you search, change or clear bindings and restore defaults. Choose a binding, press its new combination, and wait for save confirmation. Escape cancels a change. If a shortcut is already used, clear its old binding or choose another combination. Existing custom bindings take priority over newly introduced defaults.

12. Restore a snapshot or automatic backup

Choose File → Restore snapshot or Restore from backup. Select a readable version, then choose Restore selected version. Pending edits finish saving first. Restore saves a checkpoint of the current project and creates one undo step; use Undo to return to the previous cut. If the project or selected file changed, refresh the list and choose again. An uncertain restore result pauses saving: open Recovery to inspect your copies before continuing. Saved versions contain project data, so keep the referenced media files too.

Ctrl+S saves a uniquely named snapshot after pending edits finish. Agent proposal and Human final snapshots retain their training-diff workflow. A warning after a snapshot is saved reports a separate history, training or notification problem.

13. Recover a saved version or unsaved draft

Choose File → Project Recovery or Recovery in the status bar. Review the saved versions, interrupted saves, backups and browser drafts, then choose Restore selected version. Current files and your open editor copy are preserved first. Undo starts fresh for the restored project; earlier project copies remain available in Recovery.

If the app closes during restoration, reopening resolves the interrupted project and history together. Recovery may ask you to choose again if files changed or an older interrupted transaction still needs attention. A reported successful restore with a history or cleanup warning has already saved the chosen version. You can download an editor or browser-draft copy as JSON even when the server is unavailable. These copies contain project data; keep the referenced media files too.
