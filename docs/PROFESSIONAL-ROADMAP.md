This document preserves the October 4 goal and historical checkpoint plan. That local acceptance does not complete every broader professional qualification scenario below. Milestone states and host references in this dated plan are historical, not the current release verdict.

Status: **active**. Created October 4, 2026 at the user's request. Windows x64 is the release target; Linux is the current development host. Preserve the October 3 baseline, prior handoffs, user libraries and failing evidence. No feature inventory or Linux fixture count establishes a professional release.

## Completion contract

A supported editing workflow must be discoverable, reversible where appropriate, correct on representative media, and validated in the exact Windows candidate. Release requires no open data-loss, wrong-project, crash, unusable-core-workflow or incorrect-output defects in the supported scope. Every mandatory acceptance case needs an observed pass and evidence tied to that candidate. Missing hardware/dependencies and unrun native cases remain explicit gaps.

The baseline workflow is import/organize → source review → timeline/transcript editing → picture/audio treatment → captions → versions → export/review → save/reopen/archive. Include mixed integer/fractional rates, Unicode paths, mono/stereo/multichannel sources, nested sequences and long transcripts. Validate 1080p workflows first; qualify 4K, VFR, HDR/log, hardware encoders and demanding effect stacks individually with honest capability limits.

### M4a implementation checkpoint: live audio resource ownership

Clip graphs now create delay, convolution reverb, tremolo and chorus/flanger nodes only when enabled with an effective wet/depth value. Ordinary clips allocate none of these resources. Parameter redraws reuse active nodes. Pausing, muting, solo exclusion, unlinking, holds, idle voices, rendered-preview takeover and voice reset release the owned effects and stop their oscillators. The existing seek cache still retains up to sixteen idle media voices plus active voices; this does not claim that native decoder storage is released immediately.

Overlapping reverbs share one deterministic stereo 1.6-second impulse per AudioContext. Leases release the reference after the last owner leaves, and convolver buffers are detached. Returning to a cached voice reconstructs effects without creating another MediaElementSource for its element.
